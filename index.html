      Clash + mitm 本地依赖（可选，与页面脚本互补）
      1. Clash Verge 使用规则模式，仅将 reservation.sustech.edu.cn 指向本机 mitm（127.0.0.1:8080）。可用 python prepare-capture.py 生成提案配置，勿自动改写全局代理。
      2. 本机工作台在 [token] capture_mode = "mitm" 时会拉起 mitmdump；首次需信任 mitmproxy 根证书（见 README_zh.md）。
      3. 在企业微信里刷新一次预约页后，上方应显示「已抓到」，并走与页面脚本相同的验证与 TTL 探针。

      推荐：运行开始菜单「南科大场地预约」里的「配置自动获取登录」（免安装版是 配置自动获取.cmd，仓库里是 setup-capture.cmd），用 Clash Verge 自动获取登录。下面是不用 Clash 的手动方式。

      手动接入（备用）
      1. 打开企业微信，按 Ctrl+Shift+Alt+D 开启调试模式（开发者模式）。
      2. 在企业微信内打开南科大场地预约页面。
      3. 在预约页面上点右键，选择“开发者工具”，切换到 Console（控制台）。
      4. 点上方“复制连接脚本”，粘贴到 Console 后按回车，再点预约页面右下角的“连接本机控制台”。
      5. 保持连接窗口打开，在官方页面切换一次场馆，回来检查连接状态。

      连接脚本 60 分钟内有效；刷新或关闭预约页后需要重新运行。抢场前请在放号前一小时内接入。
