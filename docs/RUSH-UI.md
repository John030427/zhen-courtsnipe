# 抢场概览与过程回放

本次仅提取 PR #4 的界面，以及展示所需的只读状态字段。

- 「定时抢场」页新增「今晚的抢场」，同时显示羽毛球、网球的目标、等待倒计时和结果。
- 「过程回放」展示本轮首轮扫描、匹配、查询失败及下单结果，时间以放号时刻为零点。最多保存 80 步；内存记录随服务重启清除。
- 结束结果按北京时间日期隐藏；仍待核实的订单保留提醒。停止按钮只针对对应运动，且下单中不显示。
- 保留 main 的扫描命中后复用新鲜结果、避免重复复查的逻辑。本次不加入「放号瞬间不查询直接下单」开关、不改变扫描优先级、不延长 VID 有效期、不加入未知订单继续重试策略。

验收方式（使用测试数据或下一次本人已计划的任务）：

1. 打开「定时抢场」，确认羽毛球、网球的任务可以同时显示，切换运动不会隐藏另一项。
2. 等待时倒计时更新；展开回放后，新增步骤可见。
3. 分别检查成功、查询失败、结果待核实的文案。结果待核实时仍需在官方「我的预约」核对，界面不会声称已自动核对。
4. 浏览器刷新后可重新读取当前服务的回放；不要通过启动真实任务验证界面。

离线检查：Python unittest、`node tests/check_inline_scripts.cjs`、`node tests/rush_overview.cjs`。
