# 自动获取登录：配置方式

**推荐使用自动获取。** 工作台接入账号有两类办法：

- **自动获取**（推荐，本文）：企业微信访问预约网站时经过本机抓取代理，工作台自动拿到新 Token；配合「登录失效时自动刷新预约页并重新获取」，登录过期也能自动续上。需要一次性配置代理规则和本机证书。
- **页面脚本**（备用，什么都不用装）：企业微信按 `Ctrl+Shift+Alt+D` 开启调试模式 → 预约页右键「开发者工具」→ Console 粘贴工作台复制的连接脚本。登录失效后不能自动恢复，刷新预约页或超过 60 分钟要重新粘贴。

自动抓取提供两个渠道，效果相同，选一个即可。两者都会先检查、每一步修改前问你、自动备份，并且可以撤销。

| | 渠道 1：一键脚本 | 渠道 2：本地 agent |
| --- | --- | --- |
| 适合 | Clash Verge Rev 用户，或没有任何代理软件的电脑 | 其他代理软件、TUN 下进程路径特殊、脚本中途停下的情况 |
| 怎么用 | 开始菜单「南科大场地预约 → 配置自动获取登录」（免安装版是 `配置自动获取.cmd`，仓库里是 `setup-capture.cmd`） | 把 [LOCAL_AGENT_CAPTURE_PROMPT.md](LOCAL_AGENT_CAPTURE_PROMPT.md) 的「提示词正文」交给 Windows 上的 Claude Code / Codex |
| 撤销 | 开始菜单「撤销自动获取配置」（免安装版是 `撤销自动获取配置.cmd`，仓库里是 `undo-capture.cmd`）；卸载时也会提示 | agent 结束时给出的撤销步骤 |

## 渠道 1：一键脚本

前提：工作台已经在运行（端口 8766）：安装版双击桌面「南科大场地预约」；仓库按 README 准备好 `.venv` 后双击 `start-workbench.vbs` 启动（后台运行，不留终端窗口）。

1. 运行开始菜单里的「配置自动获取登录」（免安装版双击 `配置自动获取.cmd`，仓库里是 `setup-capture.cmd`）。
2. 脚本先列出本机情况（只读）：工作台、代理软件、Clash 模式 / TUN / 系统代理、Windows 代理设置、证书。
3. 选择路线：
   - **A. Clash Verge Rev**：在「全局扩展脚本」里追加一条 `reservation.sustech.edu.cn → 127.0.0.1:8080` 规则。原有脚本完整保留并先执行；TUN 开着时会自动加上工作台 Python 直连的例外，避免回环。改完需要你在 Clash Verge 里刷新一次（脚本不会重启 Clash）。
   - **B. Windows 设置脚本**（没有 Clash）：脚本打开 Windows 代理设置页并把地址 `http://127.0.0.1:8766/proxy.pac` 复制好，你自己打开「使用设置脚本」并粘贴保存。只有预约网站经过本机抓取代理，其他流量直连。
   - **C. 不改代理**：继续用页面脚本。
4. A、B 都会把工作台切到抓取模式，并把本机 mitmproxy 证书装到**当前用户**的信任列表（Windows 会弹窗，需要你点「是」）。
5. 完全退出并重新打开企业微信，打开预约页（已经开着就刷新一下）。脚本等到「已抓到」后，可选做一次学校只读验证（不下单）。

修改记录保存在 `%LOCALAPPDATA%\SustechReservation\capture-setup\state.json`，备份文件也在这个目录。

### 和原项目 setup.ps1 的区别

原项目（fynngwu/badminton_scripts）的一键脚本会申请管理员权限、把证书装到整台电脑、强制结束占用 8080 的程序、在 Clash 脚本格式不认识时直接替换，并强制重启 Clash。本脚本都不做：

- 不申请管理员权限，证书只装当前用户；
- 8080 被占用就停下并说明，不结束任何进程；
- Clash 全局脚本不是单个 `function main(...)` 写法、或已经有预约域名规则（包括原项目注入的 `MITM-Reservation`）时停下，不覆盖；
- 不重启 Clash、不切换规则/全局模式、不开关 TUN 和系统代理；
- 不安装 Python/uv，不修改 `[safety]`、`[user]`、订单记录。

脚本停下时会说明原因，这时改用渠道 2 或页面脚本即可。

## 未验证的部分

- 企业微信内置浏览器是否遵守 Windows「使用设置脚本」（路线 B）。如果等不到「已抓到」，运行 `undo-capture.cmd` 撤销，改用 A 或页面脚本。
- Clash Verge Rev 不同版本的配置文件名（`verge.yaml`、`clash-verge.yaml`）和界面名称。读不到时脚本按「未知」处理并在需要时停下。
- 以上流程的逻辑在 Linux 上用模拟测试和 node 实际执行 Clash 脚本验证过；Windows 实机尚未运行。
