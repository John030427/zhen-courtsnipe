# 南科大场地预约工作台 · 快速开始

适用：Windows 10 / 11（64 位）。当前推荐从 Git 安装，完整命令见 [README 快速开始](../README.md#快速开始)：使用已有的 64 位 Python，不指定小版本；先进入自己的用户目录，不能直接在 `C:\Windows\System32` 下克隆。

源码版用户：准备好 `.venv` 后，双击 `start-workbench.vbs` 可无终端窗口启动；
`run-local.ps1` 默认也在后台启动，关闭终端不会退出服务。需要前台调试时用
`run-local.ps1 -Console`。后台退出使用页面「退出服务」，或 `stop-workbench.cmd`。
源码版需准备 Git、Python 和依赖，使用 `requirements.txt` 安装。下面的 EXE / ZIP 安装说明只适用于此前发行包，不是源码安装的前置步骤。

> 默认就是**真实预约**：抢到空场会直接提交订单。每次点「开始抢场」都会先弹窗让你核对日期、时段和场地。想先试一遍流程不下单，可以在「设置 → 测试模式」里开启测试模式。

## 1. 安装

1. 双击安装程序 **`SustechReservation-Setup-<版本>.exe`**。
   - Windows 可能弹出「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。本工具没有代码签名，所以会有这个提示，只在安装时出现一次。
2. 点「下一步」→「安装」→「完成」。不需要管理员权限，装在你自己的用户目录（`%LOCALAPPDATA%\Programs\SustechReservation`）。
3. 桌面和开始菜单里会有 **「南科大场地预约」**，双击打开。几秒后浏览器会自动打开 `http://127.0.0.1:8766/`。第一次打开会有一个新手引导，一步步介绍页面，点「下一步」往下看，也可以「跳过」；以后在「设置 → 新手引导 → 再看一遍」重新打开。
   - 再次双击不会重复启动，只会重新打开页面。
4. 关闭浏览器页面**不会**停止工作台。要停止，点页面左侧「退出服务」，或开始菜单「南科大场地预约 → 停止工作台」。关机、休眠也会让它停止。

开始菜单「南科大场地预约」文件夹里还有：配置自动获取登录、撤销自动获取配置、使用说明、卸载。

- **升级**：直接运行新版安装程序，覆盖安装即可。工作台在运行的话会先让它退出；有抢场或监控任务在跑时会提示你先停止。
- **卸载**：开始菜单「卸载南科大场地预约」，或「设置 → 应用」。配置过自动获取的话，卸载时会提示先撤销（否则 Clash 仍把预约网站转到本机，预约页会打不开）。
- 你的配置、订单记录和日志保存在 `%LOCALAPPDATA%\SustechReservation\data`，升级和卸载都不会删除。
- **免安装版**：解压完整 ZIP 后，优先双击 `start-workbench.vbs`，无终端窗口；退出可用 `stop-workbench.vbs` 或页面“退出服务”。系统禁用 VBScript 时，使用 `启动工作台.cmd` 兼容入口，可能短暂显示终端，但服务在后台运行；下文的其他开始菜单项在 ZIP 里有对应 `.cmd` 文件。

## 2. 接入自己的企业微信账号

页面顶部有一条状态线：**Clash 采集 → 登录状态 → 学校验证 → 后台任务**（用页面脚本接入时第一步是「页面连接」）。前三步都变绿才算接入成功。

**推荐：用 Clash Verge 自动获取登录**（配一次即可，登录过期也能自动续上）

准备：电脑上已装好并打开 **Clash Verge Rev**，代理模式是「规则」，「系统代理」或「TUN（虚拟网卡）」至少开一个。

1. 先打开工作台（桌面「南科大场地预约」），让它运行着。
2. 开始菜单「南科大场地预约」里运行 **配置自动获取登录**。脚本先列出本机情况（只看不改），然后选 **A（Clash Verge）**。
3. 按提示逐步确认（每一步都会先问你）：
   - 同意修改 Clash Verge 的「全局扩展脚本」：只追加一条「预约网站 → 本机抓取代理」规则，原有规则不变。改完到 Clash Verge「订阅」页点一次刷新。
   - 同意安装本机证书：Windows 会弹出安全警告，点「是」。证书只装在你自己的电脑上。
   - 建议开启「登录失效时自动刷新预约页并重新获取」。
4. **完全退出企业微信**（托盘图标右键退出）再打开，进入南科大场地预约页（已经开着就刷新一下）。
5. 脚本显示「✓ 已抓到登录信息」，工作台状态线前三步变绿，就完成了。以后保持企业微信预约页开着即可。

不想用了：开始菜单里运行「撤销自动获取配置」，脚本只撤销它自己做过的修改。详细说明和其他电脑环境见 `docs\自动获取配置.md`。

**用的不是 Clash Verge（v2rayN、Clash for Windows、Mihomo Party、FlClash 等）**

原理一样：只把预约网站 `reservation.sustech.edu.cn` 交给本机 `127.0.0.1:8080`，其他流量不变；证书和抓取模式也一样。但规则要加在那个软件自己的设置里，一键脚本不会替你改。做法：打开开始菜单「其他代理软件配置说明」，复制里面的提示词，**把开头「我的情况」里的 xxx 换成你用的梯子名字等（不知道就写「不知道」）**，交给电脑上的本地 agent（Claude Code、Codex 等）。它会先只读检查认出你的软件，再一步步问你后修改，并告诉你怎么撤销。不知道梯子叫什么：看屏幕右下角托盘里的小图标，鼠标停上去会显示名字。不想折腾就用下面的页面脚本方式。

**没有 Clash 时的备用方式**

- 一键脚本里选 B「Windows 设置脚本」（不需要 Clash；企业微信是否遵守这项设置尚未验证）。
- 或者手动粘贴连接脚本：企业微信按 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>D</kbd> 开启调试模式 → 预约页右键「开发者工具」→ Console → 粘贴工作台「设置」里复制的连接脚本。这种方式 60 分钟有效，刷新预约页要重新运行，登录过期不能自动续上。

## 3. 看场地

「快速抢场」页左边是**场地实时状态**：所有场地、所有时段一张表。绿色「空」可预约，红色「占」已被预约，灰色「禁」不可约。用上方「今天 / 明天 / 后天」切换日期，「刷新全部」重新查询。

## 4. 抢场：两种方法

**先记住日期**：每天 **20:00 放的是后天的场**。比如周三晚上 8 点，抢的是周五的场。下面两种方法，日期都要选「后天」。

**方法一：20 点手动抢**

1. 20:00 一到，把场地表上方的日期切到 **「后天」**，点 **「刷新全部」**，场地表会加载出全部场地、全部时段。页面开着的话这一步会自动做：「刷新全部」旁边的「20:00 自动切到后天并刷新」默认勾选，到点自动切到后天并刷新；有定时抢场在运行就等它结束再刷新（两者共用每秒 1 次的请求名额），抢场没抢到可以马上接着手动选。
2. 点绿色「空」格子选目标（同一场地、连续、最多 2 小时），选中的会出现在右上「目标清单」里。
3. 点 **「预约所选时段」**，核对弹窗里的日期和时段，确定后直接提交订单。

**方法二：提前设好，到点自动抢（定时抢场）**

1. 右侧切到「定时抢场」。
2. 「目标日期」选 **「后天」**，再选目标场地和目标时段。「不限」按 1 号到最后一个场的顺序扫；指定某个场（或「按优先顺序」）时先扫它，没空会接着试其他场地。
3. 「计划放场时间」填 `20:00:00`（北京时间）。**放号时间和预约日期是分开的**：放号是今晚，预约的是后天。
4. 点「开始抢场」，**看清弹窗里的日期和星期是不是后天**，再核对时段、场地顺序、放号时间，无误再确定。
5. 工作台会在放号前 2 分钟复验登录，20:00 开始扫描，找到空场复查后下单。状态线「后台任务」显示进度；结束时会写明「预约成功」「未抢到」或「结果未确认」（测试模式下是「模拟完成」）。

提前设置要在**放号当天**设：「后天」是按设置时的日期算的，前一天晚上设就会差一天。

**羽毛球和网球可以同时抢**：两个运动各有一个独立的抢场任务。

1. 在「羽毛球」下设好目标，点「开始抢场」。
2. 点左上角切到「网球」，设好网球的目标，再点「开始抢场」。
3. 状态线「后台任务」会同时显示 🏸 和 🎾 两个任务。要停止哪个，就切到哪个运动点「停止抢场」。

限制：同一天两个运动的时段不能重叠（同一个人不能同时在两个场地，工作台会直接拒绝）；同一个运动同时只能有一个抢场任务，也不能和这个运动的持续监控同时运行。

## 5. 持续监控

适合「想要某天某个时间段里随便哪一小时」的情况：不用指定具体几点，只要时段里有连续够长的空场就算找到。

1. 右侧切到「持续监控」，选日期、场地、时段（比如 16:00 ~ 21:00）。监控只查你选的场地（「不限」就是全部场地）。
2. 「预约时长」选 1 / 1.5 / 2 小时：时段里任意位置有连续这么长的空场就算找到。
3. 「发现空场后」默认 **只提醒我**：弹窗提醒，不下单。选「自动预约」会直接提交订单，预约的就是这么长；约到一次就结束，「最多下单」限制实际发出的订单次数（测试模式下只模拟）。
4. 「盯多久」：默认到目标时段结束；也可以运行 30 分钟 / 1 / 2 / 24 小时（到目标时段结束也会停），或定时开始。点「停止监控」随时结束。
5. 日期按开始时选的那天算：监控「后天」，过了 0 点卡片上会显示成「明天」，盯的还是同一天。
6. 登录失效时监控不会停：先自动恢复，恢复不了就**暂停查询**（卡片变黄），每 3 分钟自动再试，你在企业微信里刷新一次预约页也能马上接上；暂停期间不会下单。
7. 关闭网页监控也不会停，但弹窗提醒要网页开着才看得到。

## 6. 测试模式（可选）

默认是真实预约，不需要切换。想先完整走一遍流程但不下单：「设置」→「测试模式」→「开启测试模式」。开启后页面顶部有黄色提示，抢场结束显示「模拟完成（未提交订单）」。用完点「关闭测试模式」恢复真实预约（有任务在运行时不能关闭）。

## 常见问题

| 看到的提示 | 原因 | 怎么办 |
| --- | --- | --- |
| 状态线「学校验证」红色「鉴权失败」 | 登录信息过期 | 开了自动恢复会自动刷新预约页重新获取；否则在企业微信里刷新一次预约页（手动粘贴脚本的方式是切换一次场馆） |
| 配置自动获取后一直「抓不到」 | Clash 规则没生效或企业微信没重启 | 确认 Clash 是规则模式、已在「订阅」页刷新、企业微信已完全退出再打开，然后刷新一次预约页 |
| 「学校验证」橙色「连接异常」 | 网络问题 | 检查网络后点「设置 → 只读复验」 |
| 抢场结束「未抢到」 | 扫描时间内没有空出目标场次 | 展开「最近场地结果」看每个场地的原因 |
| 抢场结束「结果未确认」 | 订单已发出但没收到明确结果 | **先去官方订单页核对**，不要直接重抢 |
| 「与已有订单记录冲突」 | 同一天同一时段已有成功或未确认的订单 | 核对官方订单；记录不会被自动删除 |
| 双击启动后弹窗「端口 8766 被其他程序占用」 | 有别的程序占用了端口 | 关掉那个程序再启动；本工具不会结束其他程序 |
| 双击启动后弹窗「启动失败」 | 服务没能启动 | 弹窗里有日志路径，把最后几行发给维护的同学 |
| 关掉浏览器后任务还在跑吗？ | 在跑 | 用「退出服务」或开始菜单「停止工作台」才会停止 |

## 不会做的事

工作台不会：把你的账号或 Token 发给任何第三方；在你没确认时下单；修改你的代理、VPN 或证书设置（自动抓取的一键脚本每一步都会先问你）；在关机或休眠后自动继续任务。
